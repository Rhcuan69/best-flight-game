Kestrel Run — an original 2D canvas flight game. Fly the courier plane Kestrel over the Marrow Isles: three sorties (Ring Run, Parcel Drop, Island Hop), arcade flight physics with stall, fuel and damage, and a lit instrument panel. My entry for the "Make the best flight game" bounty on make.fun.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Play it: serve `game/` with any static server and open `game/index.html` in desktop Chrome. Keyboard (arrows + W/S + Space) and mouse (drag to steer, click to drop).
