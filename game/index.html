Kestrel Run

A courier pilot over the Marrow Isles

You fly the Kestrel, a little high-wing courier aeroplane, across an archipelago of islands, sea channels and harbour villages. Pick a sortie: thread the beacon rings, drop parcels on the villages, or land on every island strip. Fuel and the airframe are both finite.

An original game: its art, sounds, names and code were made for this entry. No network requests — everything runs from these files.
